# Alfiya Khan - Premium Tech & Lifestyle Essentials

A modern, responsive e-commerce web application featuring curated audio, wearables, and workspace electronics.

## Features
- **Curated Catalog**: Browse high-end electronics and accessories with category filters and sorting.
- **Dynamic Search & Quick View**: Instant product search with detailed modal views.
- **Interactive Cart & Sandbox Checkout**: Real-time bag calculation, coupon codes, and simulated order processing.
- **Client-Side Authentication**: Member sign-in and account registration dialogs.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern Vanilla JavaScript with SVG vector icons.

## Quick Start
- Simply open `index.html` in any web browser, or double-click `start.bat`.
- Alternatively, launch a local server with `serve.ps1` in PowerShell.
